# REST Atlas

An interactive map of REST API testing tools. Explore the ecosystem, filter by capabilities, and compare tools side by side.

**[Explore REST Atlas →](https://rentgen-io.github.io/rest-atlas/)**

## Add a tool

Add your tool to the `tools` array in [tools.json](./tools.json) and open a pull request.

See [CONTRIBUTING.md](./CONTRIBUTING.md) for supported fields and examples.

## Run locally

From the project folder, run:

`python3 -m http.server 8000`

Then open http://localhost:8000
