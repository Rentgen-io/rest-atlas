A LITTLE CONTEXT

A map, not a leaderboard.

REST Atlas helps you navigate the REST API testing ecosystem by the work you need to do. No scores, sponsored positions, or claims that one tool does everything.

What belongs here?

Tools that help test REST APIs: clients, functional automation, generated tests, contracts, security, performance, mocking, and monitoring. Multi-protocol tools are included for their REST capabilities.

How to read the map

Each region previews up to three tools in a testing category, sorted by name. Use “View all” or the directory to see every match. A tool may appear in several regions. Lines connect categories that share tools; they do not imply integrations or vendor partnerships. Map positions are automatic and carry no ranking.

A small, growing collection

This first collection is a starting point, not an exhaustive market survey. Each entry links to its sources and a verification date. Features and pricing can vary by edition. Unknown means unverified, not unsupported.

Who is behind this?

Maintained by the Rentgen.io team as a community research project. Rentgen is listed under the same criteria as every other tool. Contributions and factual corrections are welcome.

Your workspace stays yours

Search and filters run in your browser. Saved tools stay in this browser’s local storage. REST Atlas has no analytics, accounts, or third-party scripts. Outbound links take you to the relevant website.
